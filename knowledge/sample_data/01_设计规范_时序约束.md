# 时序约束设计规范

## 1. 时钟约束

### 1.1 时钟周期
本设计主时钟 clock_period 为 1.0ns，工作频率 1GHz。STA 阶段使用该约束检查 setup 与 hold。

### 1.2 建立/保持时间
setup 违例表现为 WNS（最差负裕量）为负；hold 违例同样由 STA 报告。WNS/TNS 是时序收敛的核心指标。

## 2. 时序收敛标准

### 2.1 签核标准
签核（signoff）要求 setup WNS >= 0 且 hold 无违例；若 WNS 为负，需在 routing 之后执行时序优化（如插入 buffer、调整 cell 尺寸）。

### 2.2 违例处理
timing 违例的常见来源包括拥塞（congestion）与时钟树 skew 过大。IR Drop 超标也会间接导致时序恶化。
